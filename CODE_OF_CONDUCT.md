# Contributor Code of Conduct

We are committed to a welcoming, respectful, and harassment-free community.

Be constructive, assume good intent, protect user privacy, and discuss technical disagreements with evidence. Harassment, discrimination, publishing another person's private information, or knowingly introducing unsafe medical behavior is unacceptable.

For ordinary conduct concerns, contact the repository maintainers privately through GitHub. For sensitive reports, use GitHub private vulnerability reporting. Maintainers may edit or remove contributions and temporarily or permanently restrict participation when needed to protect contributors or users.
