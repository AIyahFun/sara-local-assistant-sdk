# ערכת הפיתוח לעוזר המקומי של SARA

ערכת ניסוי למתנדבים שבונים עוזר קטן המבוסס על מודל שפה מקומי עבור טאבלטי הקיוסק של SARA.

הריפו מופרד בכוונה ממערכת הייצור. הוא מכיל חוזים נייטרליים למודל, סימולטור עם מידע סינתטי, Skills לדוגמה, SDKs ותרחישי הערכה. אין בו גישה לשרת הייצור, פרטי מטופלים, הרשאות ניהול צי, סודות או credentials.

> [!IMPORTANT]
> זו ערכת מחקר ופיתוח, לא מכשיר רפואי ולא מערכת החלטה קלינית. אסור לעוזר לאבחן, להמליץ על טיפול, לחשב מינון או לקבל החלטת חירום.

## מה ניתן לפתח

- routing ובחירת tools בעברית ובאנגלית.
- adapters למודלי שפה קטנים שרצים מקומית.
- ממשק עוזר נגיש המשתמש בחוזים הציבוריים.
- Skills לקריאה בלבד וסיכומים דטרמיניסטיים.
- benchmarks על דגמי טאבלט מייצגים.

## התחלה מהירה

נדרש Node.js 22 ומעלה.

```bash
npm ci
npm test
npm run simulator
```

בחלון נוסף:

```bash
npm run sample
```

הסימולטור מאזין רק ל־`127.0.0.1` ומחזיר נתונים סינתטיים.

המודל רשאי להציע רק `tool + arguments`. קוד מארח מאומת בודק schema, הרשאה, capability, סיכון ותוצאה לפני ביצוע. פלט המודל לעולם אינו הרשאה.

להמשך קריאה: [ארכיטקטורה](docs/architecture.md), [גבול אבטחה](docs/security-boundary.md), [בניית Skill](docs/building-a-skill.md) ו־[גרסאות API](docs/api-versioning.md).

לפני תרומה יש לקרוא את [CONTRIBUTING.md](CONTRIBUTING.md) ואת [SECURITY.md](SECURITY.md). יש להשתמש בנתונים סינתטיים בלבד גם בקוד, בבדיקות, בצילומי מסך וב־Issues.
