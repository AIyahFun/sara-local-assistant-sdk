# Device help

Use this skill for requests such as “האם מד לחץ הדם מוכן?” or “Why is the scale not connected?”

1. Read the synthetic device summary before describing readiness.
2. Refer only to device kinds and safe states returned by the tool.
3. Do not invent an address, identifier, repair command, or privileged action.
4. Offer allowlisted navigation when the user needs the device screen.
5. Use at most one tool call per turn.
