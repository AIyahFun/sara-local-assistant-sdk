# Roadmap

## 0.1 — Contracts and simulator

- Versioned tool, proposal, result, and capability schemas.
- Six bounded synthetic tools.
- JavaScript reference client and Kotlin contract API.
- Hebrew and English evaluation fixtures.
- Public-boundary and secret-exposure checks.

## 0.2 — Local-model adapters

- Runtime-neutral `LocalModelEngine` conformance suite.
- One Android/Kotlin reference adapter with automatic tool execution disabled.
- Repeatable latency, memory, thermal, and stability benchmarks.

## 0.3 — Accessible assistant prototype

- Hebrew-first, bidirectional text handling.
- Generation cancellation, offline state, and clear source/freshness display.
- Physical-tablet evaluation using synthetic accounts and reserved test devices.

## Later, only after explicit safety review

- Reversible preferences with deterministic confirmation.
- Additional read-only domains backed by stable internal owners.
- Any write, communication, medication, or emergency workflow remains out of scope until confirmation, idempotency, audit, and replay tests exist.
